Mendel,MD

Open-source web software for annotating, filtering and prioritising variants from exomes and genomes in Mendelian disorders. Upload a VCF and narrow it down to a short list of candidate variants without writing code.

{% if signup_open %}Create an account{% endif %} Sign in Source code

Annotation

VCFs are annotated with Pynnotator 3, a VEP-based pipeline, using hg38 by default. Results can be exported as Parquet.

Filtering

Filter by population frequency, predicted impact, pathogenicity scores, inheritance model and gene lists.

Family analysis

Look for de novo, recessive and compound heterozygous variants across members of a family.

Publications

  • Mendel,MD: A user-friendly open-source web tool for analyzing WES and WGS in the diagnosis of patients with Mendelian disorders. PLOS Computational Biology, 2017.
  • Mendel,MD: a user-friendly online program for clinical exome analysis. BMC Bioinformatics, 2015.
